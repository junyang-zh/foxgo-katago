Connection guide
  1. Start the listener after the backend reports KataGo ready.
  2. Close FoxGTP if it occupies port 6001.
  3. In FoxGo AI management, connect to 127.0.0.1 and the port above. Enable Chinese rules and prohibit manual moves.
  4. Use FoxGo to start matches. This panel shows confirmed moves and AI analysis.

Local game controls are locked while listening. Stop the listener to return to practice.

FoxGTP relay guide
  1. Start this listener on port 8001 after the backend reports KataGo ready.
  2. In FoxGTP, connect the engine side to 127.0.0.1:8001.
  3. Connect FoxGo AI management to FoxGTP on port 6001.
