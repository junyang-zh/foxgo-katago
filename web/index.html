Connection guide
  1. Connect KataGo in Engine settings.
  2. Start this bridge. In FoxGTP select Communication → TCP/IP: FoxGTP → AI Engine; connect to 127.0.0.1 and the engine port above.
  3. Select Work → Synchronize AI to FoxClient. Set FoxGTP’s Fox client listener to 6001 and start listening.
  4. In FoxGo’s AI management, connect to 127.0.0.1:6001. Enable Chinese rules and prohibit manual moves.
  5. Leave Go common byo-yomi unchecked in FoxGTP; reserve at least 1 second for data transfer.

The panel observes online games. Local controls are locked while the bridge runs. The bridge status confirms FoxGTP only; check FoxGo’s AI indicator for its connection.
